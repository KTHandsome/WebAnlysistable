# ICP 共用介面樣式 — 2026-10-22

## 修改目的
解析資料預覽、樣品候選量測分組、批次設定、LIMS 委測配對及分析數據表共用同一套字型與表格間距。

## 實作
- 新增 static/css/icp.css，集中原有 ICP 版面及元件樣式，合併重複選擇器，移除原有分散的字級宣告。
- 匯入頁與數據頁透過既有 head block 載入，使用 icp-page 限定作用範圍；base.html 不需修改。
- 內文字級 12px、表格與表內控制項 11px、補充說明 10px、卡片標題 16px，以 CSS 變數統一調整。
- 表格儲存格間距統一 5px 4px；保留各表格欄寬、手機橫向捲動及 3B 橘色表下說明。
- 三份模板不再包含 style 區塊。保留必要欄寬與狀態顏色的行內屬性。
- 不修改資料計算、工作狀態、權限、路由、表單、JavaScript 或資料庫。

## 驗證
已檢查 Jinja 語法、移除樣式前後模板功能內容一致、CSS 語法與修補安裝流程。
實際瀏覽器驗收待使用者執行：四個匯入分頁及數據表的字型、表格與輸入欄位一致，切換與暫存仍可操作。
