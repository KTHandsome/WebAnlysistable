# ICP 品管添加濃度適用性 — 2026-10-22

## 使用者確認

任何金屬未標註括號濃度的 ICV／CCV／QC，固定代表 0.1 mg/L；MS／MSD 固定代表 0.05 mg/L。括號內數值為該列添加濃度，例如 ICV(0.01)、MS-1(0.005)。

## 本次行為

依每批次 × 金屬／波長已確認的方法設定，比對 ICV_SPIKE_CONC、CCV_SPIKE_CONC、QC_SPIKE_CONC、MS_SPIKE_CONC。使用 Decimal 比較，0.0100 與 0.01 視為相同。MSD 使用 MS_SPIKE_CONC。

明確不符的 ICV／CCV／QC／MS／MSD，不帶入區塊 2 及 3；符合濃度但實際結果不合格者仍保留判定。不依儀器實測 Conc.、訊號或回收率選取列。

同一交界 CCV 在前後批次各自比對，例如前批採用 CCV1(0.01)，後批採用未標註的 CCV1。ICBK、CCBK、BK、DUP、一般樣品不套用此濃度篩選。原始 PDF 與解析資料保留，DUP／MS／MSD 原樣關聯仍從原始量測建立。

若標籤或方法添加濃度無法確認，不自行猜測或無聲排除：保留列並顯示提示，無法據此判為合格。相同適用濃度有多筆重測時仍保留，未自動挑第一筆或最後一筆。

自動略過的來源序號、標籤、角色、標籤濃度與方法濃度，於暫存區塊 2 時一併記錄在工作狀態 auto_filtered_qaqc，既有操作者與更新時間沿用。GET 不寫入資料庫。

隔離驗證通過：全金屬未標註預設、Decimal 等值、低／高／低批次採用、交界依批次分別篩選、MS／MSD 同步篩選、原始資料不變、非依實測值選列、同濃度重測保留、暫存及重載、安裝前檢查與備份安裝。
