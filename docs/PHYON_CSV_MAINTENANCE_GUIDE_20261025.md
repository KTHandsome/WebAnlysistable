琨鼎環境科技股份有限公司檢驗室　FQ042

版本 1.0　編製日期 2026 年 10 月 25 日

本手冊供品保、系統管理者與分析方法負責人維護設定。內容涵蓋本次八份 CSV 的全部欄位、檔案關聯、更新順序、操作驗證及常見錯誤。維護時應同時核對檢測代碼、儀器、單位與已建置程式，不能只看欄位名稱或匯入成功訊息。

八份檔案實際包含七種設定用途。兩份報表設定是同一用途的兩個版本；UV_Fixed 版只修正 UV 表單標題，應擇一使用。本手冊不改動任何來源 CSV。

## 二 檔案之間如何關聯

| 起點 | 對應欄位 | 目的與維護重點 |
| --- | --- | --- |
| 方法設定 | METHOD_CODE = 年度表 EM_NUM | 依分析方法找到年度檢測項目。 |
| 方法設定與年度表 | EXAMNO 及 CATEGORY_CODE | 年度表為檢測代碼與類別的主要依據；各流程實際比對範圍不同。 |
| 方法設定 | REPORT_CODE = 報表設定 REPORT_CODE | 取得公司名稱、表單名稱、文件號及修訂版次。 |
| 方法儀器關聯 | METHOD_CODE 與 LABPARTID | 限定基本資料可選的儀器，並指定 UV／ICP 等格式。 |
| 儀器主檔 | LABPARTID | 提供選項名稱、型號；同名型號的不同設備仍以編號區分。 |
| 年度管制表 | LABPARTID 空白或等於選定儀器 | 儀器專屬管制優先；無專屬時使用空白編號的共用列。 |
| PFM 管制 | INSTRUMENT_ID = 儀器 LABPARTID | 另依監控項目、類型及分析日期選擇唯一有效管制。 |
| LIMS 委測項目 | EXAMNAME 優先 其次 EXALIAS | 透過 ICP 測項對照取得 ELEMENT 與一般／溶解態身分。 |


### 關聯不是只看一個代碼

W427 目前依年度、類別、指定 EXAMNO 及儀器取得設定，並核對測項名稱、單位與結果係數。ICP 先由年度表選批次類別及檢測代碼，再取得該元素的方法設定；現有 ICP 類別目錄程式未把方法表 CATEGORY_CODE 列為相同程度的篩選條件。舊單項共用讀取程式可能先取同方法第一筆有效方法列，因此不能把所有方法理解成同一個通用複合鍵查詢。

管理上仍應維持方法、類別與檢測代碼一致，避免依賴目前讀取順序或寬鬆比對。新增測項或改變此結構前，需用實際頁面驗證，不可只把 CSV 複製幾列就認定功能已建立。


### 版本與日期的兩種機制

一般方法與報表檔雖有 VERSION、EFFECTIVE_DATE，已核對的讀取程式主要看 ACTIVE=Y，並未自動按日期挑最新一版。報表同 REPORT_CODE 若有兩筆啟用列會直接報錯。PFM 則有獨立發布歷程，查詢要求單一 ACTIVE 發布批次，再以有效日期選控制列。兩種版本管理方式不能混用。


## 三 共通填寫與更新原則

- 使用 UTF-8 CSV，建議 UTF-8 含 BOM；第一列欄名必須保留原拼字與大小寫。不要把 MODAL 改成 MODEL，也不要用中文欄名取代原欄名。

- 代碼與序號以文字保存，保留前綴、連字號、前置零及大小寫慣例。檢測代碼以年度管制表／LIMS 為準，不自行將 W-42701 改成 W-W42701。

- 數值只填數字及半形小數點；百分比限值 80 代表 80%，不要輸入 80% 或 0.80。數值格不加單位、千分位或空白。

- 空白表示未設定或依模組預設，不等於零。MDL、上下限與添加量不能為了讓匯入通過而補 0；缺資料應先向方法負責人確認。

- 日期欄位依欄位規定填寫；PFM 支援 YYYY-MM-DD 或 YYYY/M/D。年度表建立／確認時間可保留 LIMS 原始中文上午下午格式。ISSUE_DATE 是表單顯示文字，勿和生效日混淆。

- 啟用旗標採檔案既有格式：ACTIVE／ENABLED 用 Y 或 N；年度管制 DC／QC／SPIKE／ABSV／CONFIRMED 用 1 或 0，不相互替換。

- CALIBRATION_VALUES、SAMPLE_LABELS 使用半形 | 分隔。編輯 CSV 原始文字時，包含逗號、換行或雙引號的值必須由 CSV 工具正確引用；不以手動刪除逗號修復欄位。

- 一般設定先保留完整正式檔再修改指定列。PFM 每次發布應包含完整仍適用的控制列；不可只上傳新增兩列，導致其他儀器管制不在新的 ACTIVE 批次。

- 先備份、列出變更前後差異並取得適當核定，再匯入測試環境。正式環境的 CSV、資料庫及實際執行帳號設定需分別部署；Git 同步不會同步資料庫匯入內容。

以下逐欄表的示例擷取自本次來源檔；「留存」或「依模組」表示不能假定改了該欄就會改變所有分析頁。需要新增列時，應複製同方法、同單位、同格式且已驗證的範例，再修改必要欄位。


## 四 方法設定欄位

來源為 76 列、41 欄。此檔提供檢量線、添加量、體積與結果單位等設定；它不單獨擁有所有 QA/QC 限值，也不會自動新增程式功能。

| --- | --- | --- |

| EFFECTIVE_DATE | 設定生效日，建議 YYYY-MM-DD。一般方法與報表查詢目前未依此自動切換版本，仍須配合受控匯入及有效列管理。 | 2026/1/1 |
| CATEGORY_CODE | 樣品類別代碼，須與年度表及 LIMS 的實際類別一致。W427 精確比對類別與檢測代碼；不要只由代碼外觀推定。 | W |

### 四種倍率須分開管理

| 倍率或換算 | 目的 | 避免的錯誤 |
| --- | --- | --- |
| 體積比 | 取樣與定量體積的換算 | W430 是 mg 含量轉 mg/L，不宜套一般 mg/L 體積比公式。 |
| 樣品稀釋倍數與前處理倍率 | 反映實際稀釋或前處理 | 稀釋標記已含前處理時，不再重複乘 SAMPLE_PREP_FACTOR。 |
| QAQC_CONC_FACTOR | QA/QC 計算基準的單位對齊 | 不能拿來乘入整份樣品報告或代替 3.07。 |
| RESULT_CONVERSION_FACTOR | 如 mg P/L 轉 mg PO₄³⁻/L | 不能乘入標準濃度、吸光度或 PFM。 |

QDL 的數值也受回歸單位影響。一般濃度回歸可由第一非零點乘倍率取得基準；W430 則須把 mg 除以水樣體積再換成 mg/L。畫面上的各列 QDL 可能再依稀釋倍數調整，年度表 QDL 欄不一定是此流程的實際來源。


## 五 儀器性能管制欄位

來源為 15 列、23 欄。PFM 以儀器獨立管理，不依 W／G／D 分開。檔案沒有 METHOD_CODE 欄，方法適用性由程式約定的 MONITOR_ITEM 與儀器組合決定。

| 欄位 | 用途與填寫規則 | 示例 |
| --- | --- | --- |
| CONTROL_ID | 本次完整 PFM 發布資料內的唯一管制識別，不可空白或重複。改版宜保留可追溯命名，不拿名稱代替儀器配對。 | TOC |
| INSTRUMENT_ID | PFM 所屬儀器編號，須對到儀器表 LABPARTID。同一型號的兩台設備仍應分開建立。 | A0087-02 |
| INSTRUMENT_MODEL | 儀器型號，對應儀器表 MODAL；匯入會核對已有型號資料，須使用一致文字。 | 1030W |
| YEAR | 四位西元年，如 2026，須落在有效起訖日期涵蓋年度內。讀取仍以有效日期判斷，不能只改 YEAR。 | 2026 |
| EFFECTIVE_FROM | PFM 生效日期，YYYY-MM-DD 或 YYYY/M/D。同儀器、類型及監控項目的啟用期間不可重疊。 | 2026/1/1 |
| EFFECTIVE_TO | PFM 截止日期，包含當日；不可早於起始日。跨版時要明確銜接，避免日期重疊或空窗。 | 2026/12/31 |

| NUMERATOR_ITEM | 訊號比值的分子元素，SIGNAL_RATIO 啟用列必填，例如 Se 或 Pb，且不能與分母相同。 | Se |
| NUMERATOR_WAVELENGTH_NM | 分子訊號波長數值，單位 nm，不加 nm 字樣。例如 Se 192.026。 | 192.026 |
| DENOMINATOR_ITEM | 訊號比值的分母元素，SIGNAL_RATIO 啟用列必填。例如 W311 的 Pb，M104 的 Cu。 | Pb |

### PFM 配對與發布

有效查核以單一 ACTIVE 發布批次、INSTRUMENT_ID、PERFORMANCE_TYPE、MONITOR_ITEM 及分析日期篩選。CONTROL_ID 是管制列的識別，CONTROL_VERSION 是列的版次；兩者不能取代配對欄位。啟用列的同一配對組合不得有重疊日期，起訖日視為包含當日。

已核對的匯入介面允許 SIGNAL_RATIO、SIGNAL_INTENSITY、CAL_HIGH_SIGNAL、RELATIVE_CHANGE、INSTRUMENT_CHECK 五種識別，但分析模組不必然全支援。本批實際使用 CAL_HIGH_SIGNAL 與 SIGNAL_RATIO；新增其他類型前須確認判定、歷程及趨勢圖均已接入。

W311 的 Se/Pb 與 M104 的 Pb/Cu 都是比值：先以兩個有效感應值相除再比較管制範圍，分母不可為零。W427 的 PFM_880 與 CELL_CHECK_880 則直接以吸光度判定，不套用樣品的濃度或稀釋係數。W430 420 nm 的 MAX_ABS／CELL_CHECK 與 W427 880 nm 監控名稱必須維持區分。

### 警告限與管制限

LWL／UWL 是警告下限／上限，LCL／UCL 是管制下限／上限。QC 與 SPIKE 通常是回收率百分比，DC 通常是重複分析 RPD 百分比。它們不是添加濃度、不是 MDL，也不是儀器性能 PFM 上下限。共用 QA/QC 程式會直接讀取部分界限欄，不能只填平均與 SD 就期待自動產生控制圖上下限。

年度表儀器專屬列優先於 LABPARTID 空白的共用列；既有同測項有年度管制，但指定儀器無專屬也無共用資料時，會是設定問題。相同優先層級若有多筆，不應藉調整列順序來指定哪筆生效。

- 在方法儀器關聯新增 METHOD_CODE、LABPARTID、IMPORT_TYPE，確認格式已有對應解析器。

- PFM 完整發布檔加入該台設備必要監控項目，依其實際統計資料建立上下限及生效期間。

- 若年度管制採儀器專屬，新增該儀器對應列；如採共用列，確認空白 LABPARTID 的共用資料確實適用。

- 在基本資料選此儀器，實際匯入原始檔、確認 PFM、計算、報表及歷程；格式沒有解析器時先安排程式開發。


### 更新一項 QA QC 管制範圍

先在年度表找到正確 CTRL_YEAR、CATEGORY_CODE、EXAMNO、EM_NUM 及 LABPARTID 適用層級。更新經核定的 QC／DC／SPIKE 界限及原 LIMS 確認紀錄；若同時變更添加濃度，另更新方法設定的 ICV／QC／CCV／MS 理論量，不把界限百分比填進濃度欄。用一組界限內及界限外資料驗證判定，並記錄舊新值。


### 更新一台儀器的 PFM 範圍

由最新完整 PFM 檔建立修訂副本，保留其他仍適用管制；更新目標列的核定數值、日期、CONTROL_VERSION 及 NOTES。若需保留歷史日期的適用範圍，可分成不重疊期間並使用不同唯一 CONTROL_ID。經匯入發布後確認唯一 ACTIVE 批次，測試新舊日期與各監控項目，再儲存一次檢查歷程。

既有 PFM 事件的同儀器、監控項目、類型及實測時間若已存在，相同內容可重試；改用不同控制版次或數值重新儲存同一事件可能被判定為衝突，不能藉改 CONTROL_ID 或重按按鈕覆寫歷程。

### W430 含量與 QDL 範例

W430 以 mg 含量作回歸。第一非零標準點 0.5 mg、水樣體積 100 mL、QDL_MULTIPLIER=1 時，基準 QDL = 0.5 ÷ 100 × 1000 = 5 mg/L。W427 的第一非零點是 0.02 mg P/L，不能直接套入這個含量公式。

W430 的 BKB 扣除 1.5 mg、A 液不扣 BKA 等背景處理是目前 W430 專用邏輯，不是本批方法 CSV 的通用欄位。不能把 1.5 填進 QDL_MULTIPLIER 或 QAQC_CONC_FACTOR 來建立同樣效果；W427 不使用這項背景扣除。


## 十二 更新與發布操作順序

- 備份目前正式 CSV 與相關資料庫，保留檔案日期、版本及變更前後差異。指定本次維護人及覆核人，依檢驗室既有文件程序核定。

- 以正常值、界限值、超界值及缺資料各驗一次；匯出 PDF／Excel 核對單位、文件號、位數、ND／QDL 註記與 LIMS 檢測代碼。

## 十四 常見問題與維護紀錄

| 訊息或現象 | 先檢查 |
| --- | --- |
| 查無方法設定 | 方法代碼、ACTIVE、方法檔正式名稱；新方法是否有程式入口。 |
| 儀器清單空白 | 方法儀器關聯 METHOD_CODE／LABPARTID 是否與主檔一致；不是先改 PFM 限值。 |
| 尚未設定 IMPORT_TYPE | 新 UV／ICP 關聯是否有唯一且支援的格式；不要直接用方法表的格式取代儀器分流。 |

| PFM 無法判定 | 分析日期、儀器、監控項目、類型、ACTIVE 發布批次及上下限；缺項或多筆原始量測也會阻擋。 |
