# PE900 查核列濃度與判定體積基準

本修正取代 PE900_CHECK_VOLUME_UI_20261102.md 中「僅顯示體積、濃度不換算」的規則。

- W434/W341/R318/R300 的 ICBK/ICV/CCBK/CCV，APPLY_VOLUME_FACTOR=Y 時，樣品濃度依最終定量體積／取樣體積換算；測定濃度保留儀器回歸值。25→50 mL 即乘2，倍率不寫死。
- ICV/CCV QA/QC 使用換算後樣品濃度，判定目標為原添加濃度乘同一體積倍率。例如測定0.000995、樣品0.001990、原目標0.001、判定目標0.002 mg/L，RE=-0.5%。原添加輸入保持0.001，不重複累乘。
- APPLY_VOLUME_FACTOR=N 時倍率為1；四種儀器查核仍不套額外D或前處理倍率。
- QC/MS/MSD/DUP/一般樣品、其他方法及既有查核限值不變；未帶新標記的舊工作保持原規則。新匯入後請驗證，已儲存正式快照不自動改寫。
- 修正 app.py、analysis/analysis_workflow.py、analysis/qaqc_calculator.py；保留既有四位顯示與最終體積設定。無資料庫、CSV、環境或解析器變更。

驗收：重新匯入→確認四種查核最終50 mL且樣品濃度為測定濃度2倍→ICV/CCV相對誤差不因同基準換算改變→更新、暫存及F5確認不重複乘2；再確認QC/MS/MSD仍正常。
