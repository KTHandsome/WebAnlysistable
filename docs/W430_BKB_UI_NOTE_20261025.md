# W430 BKB 扣除量提示 — 2026-10-25

- 僅 W430 在區塊 2「樣品及 QA/QC 計算」標題右側新增提示，12px、深灰色 #4b5563、一般字重，窄畫面可換行。
- 文字：BKB：回歸含量先扣除緩衝液 B 帶入的 1.5 mg 硫酸鹽，再換算濃度。
- 未修改計算、原始數據、快照、PDF 或 Excel。W434、W532 及其他方法不顯示此提示。

## 1.5 mg 的化學計量來源

依 NIEA W430.52C 配方，緩衝液 B 由 0.111 g Na2SO4 定容至 1 L，每次加入 20 mL。
Na2SO4 摩爾質量約 142.042 g/mol，SO4 約 96.06 g/mol。
帶入硫酸鹽量 = 111 mg × (96.06 / 142.042) × (20 / 1000) = 約 1.5013 mg SO4，名目量約 1.5 mg。
目前計算沿用使用者確認的 Excel 1.5 mg，不改成 1.5013 mg。此量為質量，不能當成 1.5 mg/L 或吸光度直接相減。
BKB 為緩衝液 B 空白查核；一般 B 液樣品仍依各自對應 B 空白扣除，不另扣一次固定 1.5 mg。
