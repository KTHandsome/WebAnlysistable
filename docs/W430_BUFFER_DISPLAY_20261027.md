# W430 緩衝溶液與淨含量顯示

- 共用樣品表僅 W430 在樣品編號右側增加「緩衝溶液」。原樣品及 DUP/MS/MSD 使用既有 A/B 關聯；樣品 B 空白及 BKB 顯示 B、BKA 顯示 A，未指定的查核列顯示破折號，不推定試劑。
- 樣品 B 空白保留原始吸光度及內部回歸含量，測定含量與樣品濃度顯示「－」，調整稀釋倍數也不顯示計算結果。
- W430 測定含量顯示 net_mass，與樣品濃度的體積及稀釋倍率對應。樣品及空白分別回歸後相減，未改成吸光度先相減。
- BKB 仍扣除既定 1.5 mg；A 液樣品仍不扣 BKA。原始 measured_concentration 保留，既有正式快照及匯出格式不改寫。
- 未變更其他檢項、資料庫結構、CSV、環境設定或已儲存正式紀錄。舊暫存重新更新計算後採用新呈現。

## 驗收
1. 匯入 W430 資料，核對緩衝溶液欄及原樣品/DUP/MS/MSD 關聯。
2. B 空白兩個結果欄為「－」，調整倍數、更新、暫存及 F5 後仍相同。
3. 原樣品淨含量除以取樣體積乘 1000 及 D，應等於樣品濃度（以未四捨五入值計算）。
4. BKB 扣 1.5 mg、A 液樣品不扣 BKA；其他檢項不新增欄位。
