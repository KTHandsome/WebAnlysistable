# W427 基本資料與 PFM

- 沿用共用 performance_section、performance_trend_modal、ACTIVE 管制查詢、PFM 歷程去重與衝突檢查。
- TXT 的 PFM → PFM_880；石英槽比對 → CELL_CHECK_880，均以 880 nm 吸光度直接判定。不套用 3.07、稀釋倍數或樣品背景扣除。
- 依選定儀器及基本資料分析起始日期取得有效管制；歷程保存 TXT 實際量測日期時間。
- 使用 TEST 管制版次時標示暫定測試限值；兩台儀器、兩種監控測項獨立。
- 缺項、重複項、查無管制、無效數值無法儲存；完整 FAIL 結果仍可據實儲存。
- 按「儲存 PFM」才寫入兩筆性能歷程，使用同一交易，任一項失敗全部回滾；同一事件與內容重試不新增，同一事件內容不同拒絕覆寫。
- 簽章綁定登入者、CSRF、基本資料與兩筆 PFM 原始資料；兩小時有效，儲存前重查 ACTIVE 管制，有改版則拒絕舊頁儲存。
- 不將完整分析資料存入 Flask cookie 或程序共用記憶體；本次不接入分析工作暫存、正式送審或區塊 1～3 計算。
- 本次不建立／遷移資料表，不改 CSV 或環境變數。

## Windows 驗收

1. W427 總磷、A0041-01，填寫分析起始日期，匯入 STANDARD 與 SAMPLE。
2. 兩項顯示實測吸光度、上下限與合格／不合格；2026.TEST.W427.1 顯示暫定測試提示。
3. 按儲存 PFM，頁面保留；再按一次不重複新增。
4. 兩個查看趨勢圖按鈕與性能查核查詢能找到各自紀錄。
5. 換正磷酸鹽或磷酸鹽磷，相同原始 PFM 與管制不因結果係數改變；同儀器同時間不重複新增。
