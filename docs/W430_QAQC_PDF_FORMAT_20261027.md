# W430 PDF QA/QC 格式

- ICV/CCV 相對誤差、QC/MS/MSD 回收率、DUP RPD 結果統一顯示小數一位。
- DUP 上限、MS/MSD 上下限也以小數一位顯示，既有 control_text 管制字串維持來源設定。
- DUP 原符號為小於等於（不是正負號）；改用 ASCII <=，避免部署字型缺字產生方框。± 相對誤差符號維持。
- 只調整 PDF 呈現，未修改計算精度、判定結果、資料庫或正式快照；樣品及檢量線小數位不變。
- 接續 w430_blank_pdf_patch，需先安裝前一版。

驗收：PDF QA/QC 結果如 1.8%、109.6%、0.6%；DUP 判定標準顯示 <= 15.0 %，不再有方框。
