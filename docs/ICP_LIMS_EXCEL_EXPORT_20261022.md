# ICP LIMS Excel 匯出 — 2026-10-22

## 操作與格式
- 頁首新增「匯出 LIMS Excel」，使用獨立金屬／波長勾選視窗；預選目前項目，支援全選／取消全選。
- 依左側項目順序合併成一個 ICP_LIMS_Import.xlsx，沿用 resources/lims/lims匯入表格.xlsx。
- 完整沿用 exports.lims_excel_exporter、lims_export_model，保留 Lims-品管數據及 Lims-分析數據、既有欄位、表頭、列樣式與數字格式。不新增金屬分頁或改動 LIMS 匯入欄位。
- 每批每個檢測代碼一筆品管資料。同批次／同代碼若同時選擇多個波長，提示擇一，不自動覆蓋或平均。
- 下載成功後自動關閉視窗；錯誤保留提示與勾選，未暫存輸入需先儲存。

## 對應規則
- 共用目前批次設定、檢量線、樣品計算及 QA/QC 服務，不另建計算公式。
- 品管：最高濃度標準點的測定值、批次重複分析 RPD、QC 回收率、MS 回收率、結束 CCV 相對誤差、空白試驗、批次流水號及 r。
- 起始 CCV 不代替結束 CCV；每類需有唯一明確結果，多筆不自行取第一筆或平均，提示使用者確認採用資料。
- 空白使用實際採用 BK 濃度判定，不因 BK 存在就固定輸出 <2MDL；多筆 BK 取最高濃度所對應的結果。
- 品管備註標示金屬／波長及 QA/QC 狀態，超出管制結果不改寫為合格。
- 分析數據只帶入已採用且與該批檢測代碼一致、LIMS 委測確認 ACCEPT 的一般樣品；未配對的採用原樣可供品管計算，但不建立虛構委測結果。
- 濃度依既有單測項 _build_lims_result 輸出 ND、QDL 與六位小數；批次號沿用日期＋檢測代碼＋批次序號。
- 防止同一樣品／檢測代碼產生多筆分析結果。品管與分析資料使用相同批次流水號。
- RSD 留在數據頁與 PDF；LIMS 固定匯入格式不另加欄。

## 交易與限制
- 只匯出檔案，不寫入 Phyon／LIMS、不送審、不新增資料表、不執行 Migration。
- 沿用登入與目前工作確認；驗證 CSRF、工作版本及設定／配對快照。匯出期間工作變更則不回傳檔案。
- LIMS 無法查詢、無效檢量線、樣品關聯不完整、QA/QC 無法判定、設定版本失效或缺少範本時停止匯出。
- 既有 PDF、PFM 歷程及單測項 Excel 路由／匯出器未修改。
