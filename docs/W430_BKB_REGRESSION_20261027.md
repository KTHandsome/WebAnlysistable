# W430 BKB 原始回歸含量與樣品扣除修正

此文件取代先前「B 液樣品扣 BKB 校正後含量」規則。

- BKB 測定含量 = (BKB 吸光度 - 截距) / 斜率，畫面顯示約 1.5887 mg。
- BKB 樣品濃度 = (BKB 回歸含量 - 1.5 mg) / 取樣體積(mL) × 1000 × D。100mL、D=1 時約 0.8872 mg/L；空白管制仍用此校正結果判定。
- B 液樣品及其 DUP/MS/MSD：淨含量 = 樣品原始回歸含量 - 同批次完整 BKB 原始回歸含量，再換算樣品濃度。不得改扣 BKB 的淨含量，亦不得從吸光度直接扣 1.5。
- A 液：扣對應樣品空白吸光度後回歸，維持不變。樣品 B 空白列兩個結果欄維持「－」。
- 原始 signal、measured_concentration 均保留。JS 以服務端提供之淨濃度基值乘 D，無須修改。
- 既有已正式儲存快照不自動改寫；須依退回修正流程更新。舊暫存工作按「更新樣品及 QA/QC」後重新暫存。
- 無資料庫初始化、migration、環境或 CSV 變更。

## 驗收
1. BKB 測定含量約 1.5887 mg，樣品濃度約 0.8872 mg/L（使用完整回歸精度）。
2. B 液樣品回歸含量減完整 BKB 後，再除取樣體積、乘1000及D；同批次品質管制列同步採用。
3. A 液算例 0.2064 - 0.0018，以 a=0.11406、b=-0.00161 回歸為 1.8079081185 mg。
4. 更新、調整D、暫存、F5 後結果一致；BKB 缺漏/重複時仍阻擋計算。
