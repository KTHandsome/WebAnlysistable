# W430 第二階段：共用區塊 0～3 計算預覽

日期：2026-10-24。

## 已確認規則

- 單一含截距線性回歸，STD0～STD8 依名稱排序，含量 0～4 mg；r >= 0.995。
- 回歸核心沿用 calculations/w43401.py，W430 適配層單獨採包含等號的 r 判定，不修改其他方法。
- 含量 mg = (吸光度 - 截距) / 斜率；標準 Conc 必須與方法設定逐點一致。
- A 液不扣 BKA；B 液先各自回歸為 mg，再扣除對應樣品 B 空白含量。
- 濃度 mg/L = 淨含量 mg / 水樣體積 mL * 1000 * 稀釋倍數。
- DUP/MS/MSD 使用既有原樣品及空白配對。BKB 不參與樣品扣除，空白查核公式待接入。
- QDL_MULTIPLIER 已由使用者改為 1 並重新匯入；首個非零點 0.5 mg 在 100 mL 時，QDL = 5 mg/L，再依樣品稀釋倍數調整。

## 共用介面

- 共用 performance_section、calibration_section、sample_qaqc_section、qaqc_check_section。
- 檢量線標題、判定文字及更新路由可參數化，未提供參數時保留原預設。
- 樣品的測定含量 mg 與最終樣品濃度 mg/L 分別標示，空白及 A/B 配對顯示於樣品列。
- QA/QC 使用 analysis/qaqc_calculator.py，傳入 mg/L 而非 mg。
- W430 方法設定中的 ICV/QC/CCV=2、MS=1 以添加含量 mg 解讀，轉為適用 mg/L：100 mL 時為 20、10 mg/L，再依稀釋倍數調整。此單位解讀須列入實際操作驗收。
- ICV/CCV 相對誤差以 ±15% 試算；年度 QC、DC、SPIKE 管制沿用既有設定。CCV 管制適用性列入驗收。
- 同批出現多組 DUP/MS/MSD 或不同原樣品關聯，先提示，不自動混組判定。
