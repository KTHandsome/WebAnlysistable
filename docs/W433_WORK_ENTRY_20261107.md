# W433 暫存、儲存入口與 PDF 修正

W433 改走專用 /analysis/w433/import 入口。舊 W434 連結指向 W433 工作時，先驗證擁有者再轉往專用入口，避免被 W434 工作檢查攔截。各表單與暫存連結均使用新入口。既有暫存保留，可由專用入口恢復。

正式儲存仍使用共用分析紀錄服務及交易，成功後建立待審核紀錄；重複送出及已送出工作修改仍受限制。未更動資料庫結構或初始化程序。

PDF 補上公司、表單名稱、文件編號、版次、發行日期、儀器、方法、檢驗代碼、類別與分析日期。各表格保留框線且全部白底。LIMS 維持共用匯出模組。

## 安裝
先關閉開發服務；在專案根目錄執行 check-only，成功後加 --apply。安裝程式核對來源及相依檔、檢查 Python 語法並備份；不執行資料庫操作。完成後重新啟動服務。

## 驗證
隔離 SQLite 測試：TXT 匯入、暫存 POST/redirect/GET 與重新整理、原工作重載、擁有者拒絕、正式送出只建立一筆紀錄、交易回滾、B 列濃度 NULL、送出後不可再修改；加入實際共用 before_request 邏輯確認舊連結轉向及跨使用者拒絕。PDF 已生成及視覺檢查，LIMS 使用共用 writer。尚需使用者於實際 Windows/Firebird 環境確認。
