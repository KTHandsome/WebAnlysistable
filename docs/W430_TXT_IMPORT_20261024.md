# W430 第一階段：TXT 匯入及解析預覽

日期：2026-10-24。方法：NIEA W430.52C。

## 本階段

- 基本資料新增 UV_TXT 入口及 import_w430 分流。
- 單一或多個 TXT，UTF-8 BOM／CP950，自動略過合併檔重複標題。
- 保留來源、行號、原始 Conc、吸光度與實際測定日期時間。
- STD、PFM、樣品、樣品 B 空白、BKA/BKB、ICV/CCV/QC、DUP/MS/MSD、石英槽比對及儀器 BLANK 分流。
- 420 nm 驗證、稀釋標記、批次及原樣品配對；未知及重複資料不靜默刪除。
- 有唯一同日同批同稀釋空白預帶 B，否則預帶 A；配對不明時提示。後續計算階段再提供人工調整。
- 登入、CSRF、基本資料版本驗證、大小／筆數上限；不上傳至磁碟，不寫入資料庫，不變更既有工作。
- 第一階段預覽資料只在本次回應中顯示，重新匯入須再次選取全部檔案。

## 已確認的後續計算規則（本階段尚未執行）

- 單一含截距一次線性回歸，STD0～STD8、0～4 mg，r >= 0.995。
- A 液不扣 BKA。B 液樣品及對應空白分別回歸成 mg 後相減。
- 最終 mg/L = 淨含量 mg / 水樣體積 mL * 1000 * 稀釋倍數；水樣體積預帶 100 mL。
- DUP/MS/MSD 沿用原樣品空白。BKA/BKB 僅空白查核，查核細則待核對。
- PFM 採獨立資料，不參與檢量線；判定指標與範圍尚待確認，不顯示通過。
- QA/QC 單位、QDL、正式儲存、PDF/Excel 及歷程接入屬後續階段。
