# W430 樣品空白列匯出及正式儲存

- 原正式驗證要求所有列有濃度，誤擋不計算結果的 SAMPLE_BLANK。本次僅對該角色豁免濃度要求，仍要求有效吸光度。
- 一般樣品及其他 QA/QC 列仍要求有限數值；檢量線、PFM、QA/QC 判定及原樣品關聯檢查不放寬。
- PDF 保留樣品空白列之編號、吸光度、稀釋倍數與緩衝溶液；回歸含量、扣除含量、淨含量、樣品濃度均顯示 ASCII「-」，即使舊快照曾存有空白濃度也不印出。
- PDF 計算說明同步更正：A 液先扣樣品空白吸光度再回歸；B 液扣完整 BKB 原始回歸含量。BKB 自身空白濃度才扣 1.5 mg 後換算。
- 保留 BKB 回歸含量及淨含量不同欄位，保留既有一批次一頁及 PFM/檢量線對齊。
- 此補丁不重新計算、不改寫既有快照或資料庫，不變更 CSV、環境或其他檢項。

## 驗收
1. 更新 W430 樣品及 QA/QC 後，匯出含樣品 B 空白之 PDF，不再發生「尚無有效濃度」。
2. 樣品空白結果欄為 -；一般樣品及 BKB 數值保留，一批次一頁。
3. 正式儲存同樣可通過；若一般樣品缺濃度，或樣品空白吸光度異常，仍應阻擋。
