# ICP 前後批次共用查核 — 2026-10-22

## 使用者確認規則

- BATCH1：ICBK、ICV、BK1、QC1、一般樣品及其 DUP／MS／MSD，最後為 CCBK1、CCV1。
- BATCH2：以同一筆 CCBK1、CCV1 起始，接 BK2、QC2、一般樣品及其品管，最後為 CCBK2、CCV2。
- BATCH3：以同一筆 CCBK2、CCV2 起始，依此類推。

CCBK n／CCV n 同時是第 n 批結束查核與第 n+1 批起始查核。只有確實存在的下一批才加入共用，末端查核不額外建立空白批次。

## 修正

先前以單一 sequence→batch 指派查核列，會將 CCBK n 留在下一批、CCV n 留在前一批，造成每批的前後查核不完整。本次保留一般樣品的單一批次指派，另外建立查核量測對多批次的關係。

共用量測保留相同原始序號，但各批次使用獨立工作列識別，依各批次的檢量線、方法添加濃度與管制值計算。刪除／恢復一批的查核列不影響另一批。區塊 2 與 3A 顯示起始／結束查核位置。

排除其中一批時仍保留鄰批需要的交界查核。DUP／MS／MSD 原樣關聯不跨批、不因新增交界查核而重配。3A 確認前後 ICV／CCV；本批缺少起始或結束 ICBK／CCBK 時總結顯示待確認。

原始 PDF、既有候選選擇、PFM 及方法設定不修改。舊版交界查核列因識別調整會依本批重建，畫面提示重新確認採用狀態並暫存；一般樣品與其他品管列維持既有識別。
