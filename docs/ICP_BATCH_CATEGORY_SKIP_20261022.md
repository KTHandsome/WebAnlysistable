# ICP 批次類別「不採用」— 2026-10-22

## 行為

- 批次設定的類別選單新增「不採用」，代表整批全部金屬／波長不參與後續整理，與單一金屬／波長的不採用分開處理。
- 選取後收起該批檢測代碼表格，顯示整批不採用提示；沿用「儲存全部批次設定」，F5 後保留。
- 後端 canonical category=__EXCLUDE__、is_excluded=true，並將該批全部 channel 標示排除。不需要為非 W／D／G 類樣品硬指定錯誤類別、檢測代碼或管制圖。
- 原始量測與候選預覽仍保留，不更改原始 PDF／解析 JSON。原始批次編號不重新編排。
- 重新選回有效類別會顯示檢測代碼表格，依既有規則重新確認並儲存；不默默恢復已失效的人工採用。
- 共用批次／金屬排除判定用於後續 LIMS 配對、數據頁、檢量線、樣品計算、QA/QC、PDF／Excel 匯出及正式快照的計算內容。整份原始工作仍保留於快照，以便追溯。
- 在匯入頁、數據頁及 LIMS 採用決定儲存前，先排除不採用批次的候選群組，再查詢 LIMS。相同樣品若另有採用量測，仍依採用群組查詢，不以樣品編號整個刪除。
- CCBK／CCV 共用邊界仍依批次 membership 處理；排除下一批不會刪掉前一採用批次的結束查核。
- 設定變更維持 work token／settings token／CAS 保護與既有人工採用失效歷程。
- 全批都不採用可儲存設定，但沒有採用數據時不會產生空白正式紀錄或匯出檔案。
- 不改資料表、不初始化／Migration、不變更環境設定。

## 隔離驗證

- 使用提供的 W311-TEST-1020.pdf：17 頁、4 批次、12 組金屬／波長。
- 沒有適用方法／管制設定時仍可整批排除；全部排除、部分恢復、LIMS 候選排除、數據／檢量線批次篩除、原始資料未變及共用邊界保留。
- 整批設定儲存、變更時原人工採用失效歷程、舊 work token 拒絕、不合法／空白類別拒絕。
- 類別不採用選項與回載狀態呈現、JavaScript 語法、Python 3.8 語法、唯讀預檢、備份安裝、重複安裝及異版拒絕。

## 待實際環境驗收

- 瀏覽器選取不採用、統一儲存、F5、LIMS 配對、數據頁及匯出／正式儲存僅含採用批次。
- 選回有效類別並重新確認代碼後的恢復操作。
- 來源以已套用 ICP 暫存刪除功能的版本為準；異版停止，不覆寫。
