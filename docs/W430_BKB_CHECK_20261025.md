# W430 BKB 空白查核（使用者確認）

- BKB 空白濃度＝（回歸含量 mg − 1.5 mg）÷ 水樣體積 mL × 1000。預設水樣體積 100 mL、D=1。
- BLANK_MDL_MULTIPLIER 沿用方法設定，目前為 2；濃度小於 2 MDL 顯示 <2MDL，等於或超出顯示空白超出管制。
- 原始吸光度、回歸含量及負值保留，扣除後淨含量另存 net_mass。BKB 非 D=1 時不自動計算有效濃度。
- MDL 缺少時明確顯示無法判定，不以 0 代替。
- A 液樣品不扣 BKA；B 液樣品仍分別回歸樣品與其對應 B 空白後相減，不使用 BKB 扣除。
- 載入既有暫存時重新計算顯示；再次暫存後才更新資料庫中的計算快照，不改原始 parsed_data。
- 本修正只完成 BKB 計算；正式紀錄儲存、查詢與送審仍待接入。
