- 使用者發現 W430 缺分析起始日期時 PFM 顯示英文 strptime 錯誤，並要求所有檢項共用入口檢查。
- 匯入／手動輸入按鈕離開基本資料前，以視窗一次列出缺漏欄位，聚焦第一欄；不清空已填值。
- 共用必填：管制年度、分析方法、儀器、填表日期、分析起始日期、分析結束日期；單項另需類別。多測項的類別／檢測代碼依既有批次設定，不增加入口限制；波長依原有方法確認流程，不列為通用必填。
- 日期驗證有效 YYYY-MM-DD 及結束不得早於開始，不自動改成今天或檔案日期。
- 前端與後端使用同一欄位清單。後端對六個進入分析動作同步檢查，缺漏時留在基本資料頁並顯示視窗；session 保留本次已填資料。
- 查詢管制、切換儀器及選檢測代碼未指定 next_action 時不驗證，不影響逐步選擇設定。既有工作 ID 恢復、退回修正、暫存與正式快照不經此新建入口，不重新驗證歷史欄位。

- 驗證：共同欄位缺漏、非法日期／閏日、起訖顛倒、多測項例外；隔離 Flask 入口缺漏不跳轉、查詢不攔阻、六入口有效資料仍跳轉；前端視窗與已填值保留；W430 PFM 有效值與錯誤中文。
