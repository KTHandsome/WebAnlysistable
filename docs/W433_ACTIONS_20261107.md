# W433 暫存、正式儲存與匯出

- 區塊 0 提供暫存分析資料、儲存分析紀錄、匯出檢驗紀錄表 PDF、匯出 LIMS。
- 同一工作採共用 AnalysisWorkDraft 的五組設定快照及 revision，並依登入者隔離。從 W433 入口的「我的 W433 暫存工作」重載。
- 修改稀釋倍數後直接按暫存、正式儲存或匯出，會先重新計算；檢量線測定值修改應先按「更新檢量線」。
- 原始 TXT 計算資料與目前修改分開保存，包含 A/B 原始量測、顯示順序及批次。原樣配對仍依原始 TXT 順序。
- 正式儲存沿用 save_analysis_record(strict_work_identity=True)，和暫存狀態轉換在同一個資料庫交易。成功後狀態為 UNDER_REVIEW；工作退出暫存清單，頁面隱藏暫存／儲存，保留匯出。
- 相同分析身分已有其他正式紀錄時，依共用規則拒絕另建，不自動覆寫。
- 檢量線需 r ≥ 0.995；每批 BK/QC/CCV 與第一批 ICV 必須恰有一筆；已出現但未取得有效判定的 QA/QC 不得送審或匯出。超限結果仍如實保留，不改成合格。
- PFM 檔可省略。若本工作含 PFM，正式儲存會連同有效判定與歷程關聯一併提交；不初始化或遷移資料庫。
- PDF 使用報表設定快照，A4 每批一頁，檢量線與 PFM 頂線對齊。B 空白的兩個濃度欄印 '-'，不回歸或計算；備註僅印濃度相關判讀。
- PDF 預設使用 Windows 微軟正黑體 C:\Windows\Fonts\msjh.ttc；可用 PHYON_PDF_FONT 指定字型。
- LIMS 使用既有 exports.lims_excel_exporter.build_lims_excel 及 resources/lims/lims匯入表格.xlsx。只匯出一般樣品；同一批品管各欄只能一個值，歧義時拒絕輸出。空白、MS/MSD、DUP 不當一般樣品匯出。
- 修改 routes/analysis_record_routes.py，讓已儲存的 W433 紀錄也使用 W433 專用 PDF／LIMS 配接。
- 本版未擴充退回修正入口；正式紀錄的審核／退回沿用共用流程，W433 的重新進入修正另行接入。

## 驗證
- SQLite 隔離測試：暫存／重載、所有權、版本、順序與 B 空白保留。
- 正式儲存後回滾：正式紀錄與暫存狀態一起回滾；提交成功僅一筆正式紀錄，B 空白濃度為 NULL。
- Flask request 測試：匯入 → 暫存 → redirect GET／F5 → 正式儲存；成功後隱藏寫入按鈕，重複寫入拒絕。
- 實際中文 PDF 產出與視覺檢查：測試批次一頁。
- 實際呼叫既有 LIMS Excel writer：兩張工作表、一般樣品列及品管列成功產出。
- 尚待 Windows SQLite 與 server Firebird 環境實測。
